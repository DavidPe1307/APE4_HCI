## Flujo de trabajo con git
```bash
git checkout -b aporte/<nombre>
# trabajar y hacer commits con cambios sustantivos
git add .
git commit -m "feat: descripción concreta (refs #N)"
git push -u origin aporte/<nombre>
# abrir Pull Request y pedir revisión a otro integrante
```
